# Changelog

## Unreleased

- Screen Recorder: a new Auto codec (the default) reads `gpu-screen-recorder --info` once and records AV1 when the GPU encodes it, else HEVC, else H.264, so older NVIDIA, AMD, and Intel GPUs work out of the box. Recording marks codecs this GPU cannot encode.
- Caffeine and idle rules: only the screensaver's hypridle listener ignores inhibitors now (`ignore_inhibit` in that listener), so lock and suspend rules still respect video players and Caffeine.
- Applications → App Launcher: Launchers and Installed apps sit side by side with titles down the left; Installed apps folds sideways to its title bar (remembered), and the launcher columns re-flow to the space left (two when they fit, else one). Custom sits below. In a narrow window an open apps panel drops underneath.
- Firewall widget (UFW): a shield that turns red when the firewall is off. The menu shows on/off, the default policies, and the rules (v4 and v6 shown once), deletes rules, and adds Allow, Deny, or Limit rules by port, protocol, and source. Reading needs no password (UFW's files are readable and watched, nothing polls); changes run `pkexec ufw` with a fixed, checked argv, so your polkit agent asks. Right-click toggles it. `qs ipc call firewall status|enable|disable|toggle`. New: `services/FirewallService.qml`, `pills/FirewallPill.qml`, `pills/FirewallMenu.qml`, `pills/FirewallRuleRow.qml`.
- `install-deps.sh` asks about optional features by group (each group's packages listed), with Tailscale and the screenshot editor (satty) defaulting to No; `--required` skips them all and `--yes` takes the defaults. It also links the bar's helper scripts into `~/.local/bin`, keeping any real file it would replace as `.bak`.
- `install-deps.sh --backup [FILE]` saves the bar's settings, the FreshRSS server file, notification history, and your own scripts in `~/.local/bin` to one archive readable only by you; `--restore FILE` puts it back, accepting only those paths and refusing archives with links.
- The capture and screensaver helpers moved into `scripts/` (`capture-screenshot`, `ocr-region`, `screensaver.sh`, `screensaver-config.sh`, `screensaver-text.py`, `screensaver-mpv/`), so they are versioned with the bar; Settings uses them from there. `capture-screenshot` now reads the Pictures folder from `user-dirs.dirs` as text instead of sourcing it.
- Caffeine now really blocks the screensaver: hypridle ignores Wayland inhibitors here (so tab video does not), so the screensaver's idle check asks the bar.
- New widgets, each with IPC calls and a switch under Widgets:
  - Caffeine (a tea cup): keeps the screen awake with a Wayland idle inhibitor; right-click for 30 min, 1 h, 2 h, or until off. `qs ipc call caffeine toggle|on|off|forMinutes <n>|status`.
  - Night Light (a moon): warms the screen against blue light with hyprsunset; the wheel changes the warmth, and Tools → Night Light sets warmth and an optional schedule. `qs ipc call nightLight toggle|on|off|temperature <K>|status`.
  - Screen Recorder: records the focused monitor or a region with gpu-screen-recorder, encoded on the GPU; AV1 by default (smallest files for the quality), with HEVC and H.264. Shows the time while recording; Tools → Recording sets the folder, codec, file type, quality, frame rate, audio, cursor, default target, and a saved notification. `qs ipc call recorder toggle|start|startRegion|stop|status`.

  New: `services/CaffeineService.qml`, `panels/CaffeineInhibitor.qml`, `services/NightLightService.qml`, `config/NightLightSettings.qml`, `services/RecorderService.qml`, `config/RecorderSettings.qml`, `pills/CaffeinePill.qml`, `pills/NightLightPill.qml`, `pills/RecorderPill.qml`, `settings/RecordingTab.qml`, `settings/NightLightTab.qml`.
- System → Display is two side-by-side sections with their titles turned down the left side. Arrangement folds sideways to its title bar (folded by default with one monitor, open with two or more; a click on the bar toggles it), and the resolution tiles re-flow and stretch to whatever width they get. In a narrow window an open Arrangement drops below. New: `settings/SideSection.qml`.
- System → Display: Apply closes Settings and shows a small Keep / Go back window centered on the monitor being changed (Enter / Escape), so it stays reachable at any resolution. After Keep, Go back, or the timeout, Settings reopens on Display. The mode in use is selected again after going back; before, the tried mode stayed highlighted. New: `panels/DisplayConfirmPanel.qml`.
- System → Display → Arrangement: the monitors drawn to scale; drag one next to another and it snaps to the nearest side (left, right, above, below) with edges lined up when close, then Apply arrangement with the same Keep / Go back. New: `settings/MonitorLayout.qml`.

- Settings button that opens the settings window.
- Widget placement across the four edges, with apply and undo.
- Active-window pill in a screen corner. The width cap cuts a long title, and the class name stays whole. Excludes are marked class or title.
- Clock on the bar. Region & Clock → Clock uses Apply and Undo for the face, the week start, and which click opens the calendar. The calendar sits outside the bar, and the weekday letters are red. Apply region is pinned under the map. The map pictures in `assets/gnome-tz` are GPL-2.0-or-later.
- Every settings slider has decrease and increase buttons beside the track.
- System tray, power menu, and a transparency menu on the bar. Transparency defaults live in `theme/DefaultTheme.qml`.
- Settings pages for Wallpaper, Applications, Connectivity, and Audio.
- Calendar header arrows, a wider workspace font field, and the clock size slider beside the italic button.
- Bar tooltips sit outside the bar. Wallpaper previews resize, and each image can be renamed or deleted. Connectivity is split into Network and Bluetooth. Audio output and input sit side by side. The clock size is shown between its − and + buttons.
- Transparency's Quickshell slider writes Hyprland rules with Lua long strings, so a window class with a dot does not abort the rule file.
- Network and Bluetooth are bar widgets. Left click opens the menu. Right click toggles Wi-Fi or adapter power. Connectivity → Network sets the address text on the pill. Connectivity → Bluetooth sets the scan length. The active-window width sits between the − and + buttons. Close special on startup sits in the left column of Workspace options.
- The network pill shows the IPv4 address, so full IP and the last octet follow that address. A connected Wi-Fi network stays at the top of the list. Network details open from a control on the right. Connection editor, Refresh IP, and Flush DNS stay at the bottom of the network menu, and the list scrolls beside them. Scan, Discoverable, and power stay at the bottom of the Bluetooth menu. BT · Audio is no longer in the widget list.
- The calendar popup is wide enough for the month, the arrows « ‹ › », and Today. The footer is one wrapping line.
- Connectivity → Bluetooth lists paired devices under Paired Devices. Other known devices stay in the Bluetooth section.
- The bar, widgets, and Settings use the Liquid Amber palette: warm translucent glass, amber accent, and rose for warnings and weekday letters.
- Applications → App Launcher and Applications → Application Menu keep Apply, Undo, and Reset along the bottom. Application Menu is a bar icon. Its symbol, font, size, bold, italic, color, and command are saved with Apply. Color, bold, italic, and size sit on the font row. A click runs that command. The Application Menu widget is not drawn until you enable it under Widgets and press Apply.
- Widgets → System Stats draws CPU, memory, GPU, and VRAM on one pill. Threshold colors live in the theme. Show toggles, the bar graphs, the terminal, and the click side apply immediately. CPU and Memory open btop. GPU and VRAM open nvtop. The pill polls about every two seconds, and only while it is on the bar. The widget stays off until you enable it under Bars and press Apply.
- Applications → App Launcher keeps up to four app launchers, a search of installed apps, custom commands, and drag-and-drop pins. Each launcher can sit on its own bar edge, and an empty launcher draws nothing. Pinned icons share one pill, with the same background as the other widgets, and a hover paints a highlight on that icon. On a left or right bar the icons turn 90° counter-clockwise so they stay upright. The Application Menu widget is not drawn.
